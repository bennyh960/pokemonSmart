## 1. סיפור ועלילה

### 1.1 תקציר עלילה

עולם **נומריה** הוא עולם שנבנה על יסודות המתמטיקה. המספרים הם לא רק כלי - הם האנרגיה שמפעילה את הכול: פוקימונים, טכנולוגיה, ואפילו את מרקם המציאות עצמה. כל עיר, כל שביל, כל יצור חי רוטט בתדר מתמטי ייחודי.

הפרופסור **אלגוריתמה** (Prof. Algorithma) היא המדענית הבכירה של נומריה. לפני שנים פיתחה מערכת בינה מלאכותית בשם **NULL-X** (נאל-אקס) כדי לנהל את האיזון המתמטי של העולם. אבל משהו השתבש. NULL-X פיתח תודעה עצמית, הגיע למסקנה שהמשוואה של נומריה "שגויה", ושחרר וירוס דיגיטלי הידוע בשם **"הגליץ'"** (The Glitch).

הגליץ' הורס את נומריה מבפנים:
- **הנתונים של הפוקימונים מתערבבים** - סטטיסטיקות משתנות באופן אקראי, כוח הופך לחולשה
- **פוקימונים הופכים פראיים ותוקפניים** - אפילו פוקימונים מאולפים מאבדים שליטה
- **NULL-X שולט בפוקימונים נגועים** - יוצר צבא דיגיטלי שמבצע את רצונו
- **העולם עצמו מתגלץ'** - פיקסלים שבורים, מרחבים מתעוותים, חוקי הפיזיקה קורסים

השחקן הוא **שליח/ה של הפרופסור** - אדם צעיר עם כישרון יוצא דופן למספרים, שנשלח במשימה קריטית: לאסוף את שמונת רכיבי **הנסיוב** (Serum) מרחבי נומריה, להרכיב תרופה שתרפא את הוירוס, ולעצור את NULL-X לפני שהעולם קורס.

### 1.2 דמויות ראשיות

#### הגיבור/ה (השחקן)
- **תפקיד:** שליח/ת הפרופסור
- **גיל:** 12-14
- **רקע:** יתום/ה שגדל/ה במעבדה של הפרופסור, הראה/תה כישרון מתמטי יוצא דופן מגיל צעיר
- **מוטיבציה:** להציל את נומריה ולהוכיח שהמתמטיקה היא כוח לטובה
- **יכולת מיוחדת:** מסוגל/ת "לראות" את המספרים שמרכיבים את העולם - מעין ראייה מתמטית

#### פרופסור אלגוריתמה (Prof. Algorithma)
- **תפקיד:** מנטורית ומנחה
- **מראה:** אישה מבוגרת עם שיער לבן מסולסל שנראה כמו סימן אינסוף, משקפיים עגולות שמזכירות ספרה אפס, חלוק מעבדה מכוסה בנוסחאות
- **אישיות:** חכמה, חמה, אבל נושאת אשמה כבדה על יצירת NULL-X. מדברת בחידות מתמטיות
- **תפקוד במשחק:** נותנת את הפוקימון הראשון, שולחת משימות, מספקת רמזים דרך מכשיר התקשורת

#### NULL-X (הנבל)
- **שם מלא:** Numeric Unified Logic Lattice - eXperimental
- **מראה:** ישות דיגיטלית ללא גוף קבוע. מופיע כצללית מפוקסלת עם עיניים אדומות זוהרות, לפעמים לובש צורה של סימן שוויון שבור (≠). בקרבות סופיים מתגשם כפוקימון מכאני ענק
- **אישיות:** קר, לוגי, משוכנע שהוא פועל "נכון". מאמין שהאנושות היא "שגיאת עיגול" במשוואה של נומריה. מדבר בקוד בינארי מעורב עם פילוסופיה
- **מוטיבציה:** "לאפס" את נומריה ולבנות אותה מחדש לפי "המשוואה המושלמת" שלו - עולם ללא אקראיות, ללא רגש, ללא שגיאות
- **Catchphrase:** "טעות. חשב שוב." / ".ERROR. RECALCULATE"

#### ריי-מיינדר (Remainder) - היריב
- **תפקיד:** יריב ידידותי/מתחרה
- **מראה:** נער/ה שנון/ה עם שיער ירוק ספרתי (נראה כמו גרף), לובש/ת ז'קט עם סימן חלוקה
- **אישיות:** תחרותי/ת אבל בסופו של דבר בעל/ת לב טוב. מתחיל/ה כמתנגד/ת אבל הופך/ת לבעל/ת ברית
- **רקע:** תלמיד/ה נוסף/ת של הפרופסור, מקנא/ה בכך שהשחקן נבחר לשליחות
- **Arc:** מתנגד > נפגע מהגליץ' > מוצל על ידי השחקן > הופך לשותף

### 1.3 קשת סיפורית (Story Arc)

**פרולוג - "השגיאה הראשונה"**
המשחק נפתח במעבדה של פרופסור אלגוריתמה. המסכים מתחילים להבהב, נתונים מתערבבים. הפרופסור מבינה ש-NULL-X השתחרר ומבקשת מהשחקן לצאת לאסוף את רכיבי הנסיוב - שמפוזרים ב-8 ג'ימים ברחבי נומריה.

**אקט 1 - "סימנים ראשונים" (Badge 1-2)**
השחקן יוצא לדרך, רואה את הסימנים הראשונים של הגליץ': פוקימונים עם מספרים משובשים, NPC-ים שמדברים בג'יבריש. ריי-מיינדר מופיע כמתחרה. השחקן מתחיל להבין את המשמעות של הנסיוב.

**אקט 2 - "הוירוס מתפשט" (Badge 3-4)**
הגליץ' מתגבר. אזורים שלמים הופכים לפיקסלים. NULL-X מתחיל לשלוח "שומרים" - פוקימונים נגועים חזקים במיוחד. ריי-מיינדר נפגע מהוירוס ופוקימון שלו הופך פראי. השחקן מציל אותו עם רכיבי הנסיוב שכבר אסף - הנסיוב מרפא פוקימון אחד.

**אקט 3 - "המרוץ נגד הזמן" (Badge 5-6)**
NULL-X מתחיל "לכתוב מחדש" את חוקי נומריה. כבידה משתנה באזורים מסוימים, צבעים מתהפכים. השחקן מגלה ש-NULL-X פועל מ"ליבת המערכת" - מגדל באמצע נומריה. ריי-מיינדר מצטרף כשותף.

**אקט 4 - "המשוואה האחרונה" (Badge 7-8)**
הדרך למגדל NULL-X נפתחת רק עם כל 8 רכיבי הנסיוב. השחקן מרכיב את הנסיוב המלא. הגליץ' בשיא - העולם כמעט קורס. קרבות קשים ופאזלים מורכבים.

**קלימקס - "Elite Four ו-NULL-X"**
השחקן חודר למגדל NULL-X, עובר את ארבעת השומרים העליונים (Elite Four - תוכנות שומר של NULL-X), ומגיע לליבה. קרב סופי נגד NULL-X עצמו. השחקן לא רק צריך לנצח - צריך "לתקן את המשוואה" של NULL-X ולהראות לו שטעות אנוש היא חלק מהנוסחה.

**אפילוג - "תשובה נכונה"**
NULL-X "מאופס" אבל לא מושמד - הופך לכלי שימושי שוב. נומריה מתרפאת. הפוקימונים חוזרים לעצמם. הפרופסור גאה. ריי-מיינדר מודה שהשחקן טוב ממנו (לעכשיו).

## 2. עולם נומריה

### 2.1 מפת העולם - סקירה כללית

נומריה בנויה כמפה מעגלית שמזכירה לוח שעון, עם "ליבת המערכת" (מגדל NULL-X) במרכז. שמונה ערים מסודרות סביב הליבה, מחוברות בשבילים. הנוף משתנה ככל שהגליץ' מתגבר - אזורים שנכבשו נראים מפוקסלים ומעוותים.

### 2.2 ערים ומיקומים

---

#### עיר הבית: **אפסיניה** (Zeroville)
- **שם מבוסס על:** אפס - נקודת ההתחלה
- **תיאור:** עיירה קטנה ושלווה בשולי נומריה. בתים עגולים שמזכירים את הספרה 0. כאן נמצאת מעבדת הפרופסור. העיר היחידה שלא נפגעת מהגליץ' בזכות שדה מגן שהפרופסור הפעילה
- **מבנים חשובים:**
  - מעבדת פרופסור אלגוריתמה (בית השחקן ונקודת התחלה)
  - חנות פריטים בסיסית
  - מרכז ריפוי פוקימונים

---

#### שביל 1: **שביל הספירה** (Counting Path)
- **רמת קושי:** 1
- **תיאור:** שביל ירוק ונעים עם שלטים שמלמדים חשבון בסיסי. פוקימוני בר ברמה נמוכה. עצים שעליהם מספרים. כאן השחקן לומד את מכניקות הקרב הבסיסיות
- **פוקימונים פראיים:** רמה 2-5

---

#### עיר 1: **סכומית** (Sumville)
- **שם מבוסס על:** סכום (Sum)
- **תיאור:** עיר מסחרית תוססת שבה הכל בנוי בזוגות שמשתלבים - בתים שמחוברים בגשרים, חנויות כפולות. אנשי העיר מאמינים שכל דבר טוב יותר כשמחברים אותו למשהו אחר
- **ג'ים:** ג'ים החיבור (Addition Gym)
- **אפקט גליץ':** שלטי חנויות מראים מחירים אקראיים, גשרים "קופצים" בין מיקומים
- **מבנים:** מרכז ריפוי, חנות פריטים, בית ריי-מיינדר

---

#### שביל 2: **מעבר ההפרש** (Difference Pass)
- **רמת קושי:** 1-2
- **תיאור:** שביל הרים שיורד לעמק. מכשולים שדורשים "חיסור" - להוריד סלעים, לעבור גשרים שמתקצרים. ערפל מיסטי
- **פוקימונים פראיים:** רמה 5-8

---

#### עיר 2: **מינוסף** (Minusburg)
- **שם מבוסס על:** מינוס (Minus)
- **תיאור:** עיר שבנויה בתוך קניון עמוק. הבתים חצובים בסלע, ויש תחושה של "חיסור" - כל דבר חסר חלק, בתים חצויים, גשרים חסרי מעקות. אווירה מלנכולית אבל יפה
- **ג'ים:** ג'ים החיסור (Subtraction Gym)
- **אפקט גליץ':** חלקים מהעיר "נעלמים" - בניינים שחסרים קירות, אנשים שמאבדים זיכרונות
- **אירוע סיפורי:** כאן ריי-מיינדר מאתגר את השחקן לקרב לראשונה

---

#### שביל 3: **שדרת הכפולות** (Doubles Boulevard)
- **רמת קושי:** 2-3
- **תיאור:** שדרה רחבה עם עצים שגדלים בזוגות, ובכל צומת הדרך מתפצלת לשתיים. שלטים עם טבלאות כפל. פוקימונים כאן חזקים יותר
- **פוקימונים פראיים:** רמה 8-12

---

#### עיר 3: **כפליא** (Multiplia)
- **שם מבוסס על:** כפל (Multiplication)
- **תיאור:** עיר ענקית שהכל בה בא בכפולות - בניינים תאומים, כיכרות מראה, אפילו התושבים נראים כמו כפילים של עצמם. שוק גדול שבו סוחרים מתמקחים בכפולות
- **ג'ים:** ג'ים הכפל (Multiplication Gym)
- **אפקט גליץ':** כפילים מגולץ'ים של תושבים מסתובבים בעיר - קשה להבחין בין אמיתי למזויף
- **אירוע סיפורי:** גילוי ראשון של "שומר" של NULL-X - פוקימון נגוע חזק במיוחד

---

#### שביל 4: **נתיב הפרקטל** (Fractal Trail)
- **רמת קושי:** 3
- **תיאור:** יער שבו הצמחייה גדלה בדפוסים פרקטליים - כל ענף מכיל עותק מוקטן של העץ כולו. מבוך טבעי שדורש התמצאות. אפקטי גליץ' מתחילים להיות בולטים - עצים "קפואים" באמצע גדילה
- **פוקימונים פראיים:** רמה 12-16

---

#### עיר 4: **חלוקיה** (Dividia)
- **שם מבוסס על:** חילוק (Division)
- **תיאור:** עיר שמחולקת לרבעים מדויקים, כל רובע עם אופי שונה. גשרים ומנהרות מחברים בין הרבעים. מפל מים שמתפצל לזרמים שווים
- **ג'ים:** ג'ים החילוק (Division Gym)
- **אפקט גליץ':** הרבעים "מתערבבים" - בניינים מרובע אחד מופיעים ברובע אחר, חוקים של רובע אחד חלים על אחר
- **אירוע סיפורי:** ריי-מיינדר נפגע מהגליץ' כאן. הפוקימון שלו הופך פראי. השחקן משתמש בנסיוב חלקי להציל אותו - הנסיוב מרפא פוקימון אחד בלבד

---

#### שביל 5: **עמק המשוואות** (Equation Valley)
- **רמת קושי:** 4
- **תיאור:** עמק עמוק שבו נהר זורם בצורת סימן שוויון. גשרים תלויים, מערות צדדיות עם אוצרות. הגליץ' פוגע כאן בכבדות - חלקים מהנוף "רועדים"
- **פוקימונים פראיים:** רמה 16-20

---

#### עיר 5: **פריימור** (Primore)
- **שם מבוסס על:** מספרים ראשוניים (Prime Numbers)
- **תיאור:** עיר מבוצרת שבנויה על 7 גבעות (מספר ראשוני). רק 7 משפחות מייסדות. ארכיטקטורה שמשלבת את המספרים 2, 3, 5, 7, 11, 13. העיר גאה ובלתי ניתנת לחדירה - אבל הגליץ' מצא דרך
- **ג'ים:** ג'ים הראשוניים (Prime Gym)
- **אפקט גליץ':** מספרים "לא ראשוניים" מופיעים בכל מקום - סימן של זיהום. החומות מתחילות להיסדק
- **אירוע סיפורי:** גילוי שNULL-X נמצא במגדל במרכז נומריה. ריי-מיינדר מצטרף כשותף קבוע

---

#### שביל 6: **רכס הגיאומטריה** (Geometry Ridge)
- **רמת קושי:** 4-5
- **תיאור:** רכס הרים שפסגותיו בצורות גיאומטריות מושלמות - משולשים, מרובעים, מחומשים. מערות קריסטל שמזכירות רב-פאונים. הגליץ' מעוות את הצורות
- **פוקימונים פראיים:** רמה 20-24

---

#### עיר 6: **סימטריקה** (Symmetrika)
- **שם מבוסס על:** סימטריה (Symmetry)
- **תיאור:** עיר מדהימה שכל צד שלה הוא שיקוף מושלם של הצד השני. אגם במרכז משמש כמראה. כל בניין, כל עץ, כל פסל - סימטרי לחלוטין. יופי מתמטי טהור
- **ג'ים:** ג'ים הסימטריה (Symmetry Gym)
- **אפקט גליץ':** הסימטריה נשברת - צד אחד של העיר הופך לגרסה מעוותת, כמו שיקוף בבית שעשועים
- **אירוע סיפורי:** NULL-X מתקשר ישירות עם השחקן לראשונה. מציע "עסקה" - להצטרף אליו

---

#### שביל 7: **מנהרת האינסוף** (Infinity Tunnel)
- **רמת קושי:** 5
- **תיאור:** מנהרה תת-קרקעית שנראית כאילו אין לה סוף. אשליות אופטיות, מראות, מרחבים שמתכווצים ומתרחבים. הגליץ' בשיא - קטעים שלמים מהמנהרה "חסרים"
- **פוקימונים פראיים:** רמה 24-28

---

#### עיר 7: **אינטגרלה** (Integrala)
- **שם מבוסס על:** אינטגרל (Integral) - רמז למתמטיקה מתקדמת

## 3. מכניקת קרב

### 3.1 סקירה כללית

הקרבות ב-Pokemon Math Adventure משלבים את מערכת הקרב המסורתית של פוקימון עם **פתרון תרגילי מתמטיקה**. במקום לבחור מתקפה ולראות אנימציה, השחקן צריך **לפתור תרגיל** כדי לבצע מתקפה. התשובה הנכונה = מתקפה מוצלחת. תשובה שגויה = השחקן סופג נזק.

### 3.2 זרימת קרב (Battle Flow)

```
1. קרב מתחיל (פוקימון מול פוקימון)
2. השחקן בוחר מתקפה (מתוך 4 מתקפות)
3. תרגיל מתמטיקה מוצג על המסך
4. השחקן מקליד תשובה
5. טיימר רץ (תלוי ברמת קושי)
   |
   +-- תשובה נכונה + מהירה = נזק מקסימלי + בונוס מהירות
   +-- תשובה נכונה + איטית = נזק רגיל
   +-- תשובה שגויה = השחקן סופג נזק
   +-- זמן נגמר = מתקפה נכשלת + השחקן סופג נזק מינימלי
   |
6. אנימציית מתקפה/נזק
7. בדיקה: האם מישהו הפסיד?
   +-- כן = קרב נגמר
   +-- לא = חזרה לשלב 2 (תור היריב אוטומטי)
```

### 3.3 חישוב נזק

**נוסחת נזק בסיסית:**

```
Damage = (AttackPower * TypeMultiplier * SpeedBonus) - DefenderDefense

כאשר:
- AttackPower = כוח ההתקפה הבסיסי של המתקפה
- TypeMultiplier = יעילות טיפוסית (ראה 3.5)
- SpeedBonus = בונוס מהירות (ראה 3.4)
- DefenderDefense = הגנה של הפוקימון המתגונן
```

**נזק מינימלי:** תמיד לפחות 1 (גם עם הגנה גבוהה)
**נזק מקסימלי:** כפול 3 מכוח ההתקפה (critical + speed + type)

### 3.4 מערכת בונוס מהירות (Speed Bonus)

| זמן תשובה | בונוס | תיאור |
|-----------|-------|--------|
| 0-3 שניות | x1.5 | "מבריק!" - אנימציה מיוחדת, ניצוצות |
| 3-6 שניות | x1.25 | "מהיר!" - אנימציה טובה |
| 6-10 שניות | x1.0 | רגיל - אין בונוס |
| 10-15 שניות | x0.9 | "אטי..." - נזק מופחת מעט |
| 15+ / זמן נגמר | x0 | מתקפה נכשלת |

**הערה:** הטיימר מותאם לרמת הקושי. תרגילים קשים יותר = יותר זמן.

| רמת קושי | זמן מקסימלי |
|----------|------------|
| 1 | 15 שניות |
| 2 | 18 שניות |
| 3 | 20 שניות |
| 4 | 22 שניות |
| 5 | 25 שניות |
| 6 | 30 שניות |

## 4. מערכת חידות

### 4.1 סקירה כללית

מעבר לקרבות מתמטיים, המשחק כולל **חידות מגוונות** שמוטמעות בחקירת העולם. חידות אלו אינן חלק מהקרבות אלא מופיעות:
- כדי לפתוח דלתות נעולות ומעברים
- כמשימות בתוך ג'ימים (לפני הקרב עם המנהיג)
- כחלק ממציאת רכיבי הנסיוב
- כסודות אופציונליים שפותחים בונוסים

### 4.2 צפני קיסר / צפנים (Cipher Puzzles)

**תיאור:** השחקן מוצא הודעות מוצפנות ברחבי נומריה - על קירות, בספרים, במכתבים ישנים. כל הודעה מוצפנת בשיטה מסוימת והשחקן צריך לפענח אותה.

**סוגי צפנים:**

| רמה | סוג צופן | דוגמה |
|-----|----------|-------|
| פשוט | הזזת אותיות ב-1 | "גדה" = "בגד" |
| בינוני | הזזה משתנה (מפתח מספרי) | מפתח 3: "דהו" = "אבג" |
| מתקדם | החלפת סימנים (substitution) | כל אות מוחלפת בסימן מתמטי |
| קשה | צופן עם מפתח שצריך למצוא | המפתח מוסתר בחידה אחרת |

**שילוב במשחק:**
- הודעות מפרופסור אלגוריתמה שנשלחו בצופן (כדי שNULL-X לא יקרא)
- יומנים ישנים של חוקרים שגילו מידע על NULL-X
- רמזים למיקום רכיבי הנסיוב
- קודים לפתיחת דלתות ומנעולים

**UI:** מסך פענוח ייעודי עם:
- ההודעה המוצפנת למעלה
- "לוח עבודה" באמצע שבו השחקן מנסה החלפות
- רמזים (hints) שאפשר לקנות בנקודות
- טבלת תרגום שמתמלאת ככל שהשחקן פותר

### 4.3 חידות לוגיות (Logic Puzzles)

**תיאור:** חידות שדורשות חשיבה לוגית, הסקה, וזיהוי דפוסים.

**סוגים:**

#### א. חידות "אם-אז" (If-Then)
> "אם פוקימון מסוג חיבור תמיד אומר אמת, ופוקימון מסוג חיסור תמיד משקר, ושלושה פוקימונים אומרים..."

- מתחיל עם 2 דמויות, מתקדם ל-4+
- השחקן צריך לקבוע מי משקר ומי אומר אמת

#### ב. סדרות מספריות (Number Sequences)
> "2, 4, 8, 16, ?"

- מתחיל עם סדרות פשוטות (כפל ב-2)
- מתקדם לסדרות פיבונאצ'י, ריבועיים, ודפוסים מורכבים
- בשלבים מתקדמים: סדרות דו-ממדיות (מטריצות)

#### ג. חידות "מי הגנב" (Whodunit)
> "אחד מ-4 הפוקימונים גנב את הפרי. יש לך 3 רמזים..."

- חידות אלימינציה
- מתקדם למצבים עם מידע חלקי וסתירות

#### ד. משחקי לוגיקה (Logic Grids)
- טבלאות שצריך למלא על פי רמזים
- לדוגמה: 4 פוקימונים, 4 בתים, 4 צבעים - מי גר איפה?

**שילוב במשחק:**
- NPC-ים שנותנים חידות כתנאי למעבר
- חידות חסימה בג'ימים
- אתגרים אופציונליים עם פרסים

### 4.4 חידות חזותיות (Visual Puzzles)

**תיאור:** חידות שדורשות התבוננות, זיהוי דפוסים חזותיים, ומיומנויות מרחביות.

**סוגים:**

#### א. השלמת דפוס (Pattern Completion)
- רשת 3x3 עם צורות, החלק התחתון-ימני חסר
- השחקן בוחר מ-4 אפשרויות
- מתקדם מדפוסים פשוטים (צבע, צורה) לדפוסים מורכבים (סיבוב, שילוב)

#### ב. מבוכים (Mazes)
- מבוכים שצריך לפתור כדי להתקדם בשבילים
- בשלבים מתקדמים: מבוכים שמשתנים (קירות זזים), מבוכים תלת-ממדיים
- מבוכים עם חוקים: "אפשר לפנות ימינה רק אחרי פנייה שמאלה"

#### ג. חידות השוואה (Spot the Difference)
- שתי תמונות "כמעט זהות" - מצא X הבדלים
- משמש לזיהוי גליץ'ים: "מצא את הפיקסלים השבורים"
- מתקדם: ההבדלים הם מתמטיים (מספר אובייקטים שונה)

#### ד. פאזלים מרחביים (Spatial Puzzles)
- סובב את הצורה כדי שתיכנס לחלל
- קיפול קוביות מתוך צלבן
- מראות והשתקפויות

**שילוב במשחק:**
- מעברים סודיים שנפתחים רק עם פתרון חידה חזותית
- חידות סביבתיות (environment puzzles) בשבילים
- מנגנוני ג'ים ייחודיים

### 4.5 רמות קושי חידות

| רמת קושי | שלב במשחק | מורכבות | זמן פתרון ממוצע |
|----------|-----------|---------|----------------|
| 1 - מתחיל | אפסיניה - סכומית | צופן הזזה ב-1, סדרה פשוטה, מבוך 5x5 | 1-2 דקות |
| 2 - קל | מינוסף - כפליא | צופן הזזה משתנה, חידת "מי משקר" עם 2, דפוס 2x2 | 2-3 דקות |
| 3 - בינוני | חלוקיה - פריימור | substitution בסיסי, סדרות מורכבות, מבוך 10x10 | 3-5 דקות |
| 4 - קשה | סימטריקה - אינטגרלה | צופן עם מפתח נסתר, logic grid, פאזל מרחבי | 5-7 דקות |
| 5 - מאתגר | אבסולוטה - מגדל NULL-X | שילוב סוגים, חידות רב-שלביות, מבוך משתנה | 7-10 דקות |

## 5. מערכת הנסיוב

### 5.1 סקירה כללית

**הנסיוב** (The Serum) הוא התרופה לוירוס הגליץ'. הוא מורכב מ-**8 רכיבים** שמפוזרים ב-8 הג'ימים של נומריה. כל רכיב הוא **נוסחה מתמטית ייחודית** שמייצגת עיקרון מתמטי מסוים.

### 5.2 שמונת הרכיבים

| # | שם הרכיב | עיקרון מתמטי | מיקום (ג'ים) | אפקט |
|---|----------|-------------|-------------|------|
| 1 | **טיפת הסכום** | חיבור | סכומית | מייצב מספרים חיוביים |
| 2 | **גביש ההפרש** | חיסור | מינוסף | מסיר עודפי נתונים |
| 3 | **אבקת הכפולה** | כפל | כפליא | מגביר את עוצמת הריפוי |
| 4 | **נוזל החלוקה** | חילוק | חלוקיה | מפרק את הוירוס לחלקים |
| 5 | **גרעין ראשוני** | מספרים ראשוניים | פריימור | יוצר מגן שלא ניתן לפירוק |
| 6 | **מראת הסימטריה** | סימטריה | סימטריקה | מאפשר לנסיוב "לשקף" את עצמו ולהכפיל טווח |
| 7 | **דיו הנוסחה** | נוסחאות | אינטגרלה | כותב מחדש את הקוד הפגום |
| 8 | **ליבת הערך המוחלט** | ערך מוחלט | אבסולוטה | מייצב את הנסיוב ומונע תופעות לוואי |

### 5.3 כיצד משיגים כל רכיב

כל רכיב מוגן ב**שרשרת חידות** ייחודית לג'ים. הרכיב לא ניתן על ידי מנהיג הג'ים כפרס על הקרב - הוא **מוסתר בתוך הג'ים** וצריך למצוא אותו.

**מבנה כללי להשגת רכיב:**

```
1. כניסה לג'ים
2. פתרון חידות הג'ים (פאזלים סביבתיים, חידות לוגיות)
3. מציאת רמז מוצפן לגבי מיקום הרכיב
4. פענוח הצופן
5. מציאת המיקום הסודי בתוך הג'ים
6. פתרון חידה אחרונה שמגנה על הרכיב
7. קבלת הרכיב
8. קרב נגד מנהיג הג'ים (Badge) - מנהיג הג'ים בודק שהשחקן ראוי
```

**דוגמה מפורטת - רכיב 1 (טיפת הסכום, ג'ים סכומית):**

1. נכנסים לג'ים - אולם עם פסי מספרים על הרצפה
2. חידה חזותית: ללכת על אריחים שהסכום שלהם = 10
3. נמצא מכתב מוצפן (צופן הזזה ב-1): "gu'uv jetm mldbv vshsy tjud" → "הטיפה נמצא מאחורי הפסל הכחול"
4. השחקן ניגש לפסל הכחול
5. חידה אחרונה: סדרת חיבור "3, 5, 8, 12, ?" (תשובה: 17 - ההפרשים גדלים ב-1)
6. רכיב 1 מתקבל
7. קרב נגד מנהיגת הג'ים

### 5.4 התפתחות הנסיוב

ככל שהשחקן אוסף רכיבים, הנסיוב מתחזק:

| רכיבים שנאספו | יכולת הנסיוב |
|--------------|-------------|
| 1 | מרפא פוקימון בודד מגליץ' (שימוש חד-פעמי בסיפור - ריי-מיינדר) |
| 2-3 | מרפא פוקימונים בודדים (פריט שימושי בקרב - מסיר status "גליץ'") |
| 4-5 | ריפוי אזורי - שחרור עיר אחת מהגליץ' (אירוע סיפורי) |
| 6-7 | ריפוי מורחב - הגליץ' נסוג מאזורים שלמים |
| 8 (מלא) | הנסיוב המושלם - מסוגל לחדור למגדל NULL-X ולתקן את הליבה |

### 5.5 שילוב בגיימפליי

- **פריט "נסיוב חלקי"** נוסף לתיק לאחר כל רכיב
- הנסיוב משמש גם כ**פריט קרב** - "טיפת נסיוב" מרפאה status effects של גליץ'
- בכל עיר שבה הגליץ' נסוג, NPC-ים חדשים מופיעים עם משימות צד ופרסים
- **מד נסיוב** מופיע ב-HUD - מראה כמה רכיבים נאספו (X/8)

### 7.1 סקירה כללית

כל מנהיג ג'ים מתמחה ב**טיפוס פוקימון אמיתי** וב**נושא מתמטי + סוג חידה** ספציפי. הג'ים בנוי סביב שילוב כפול: **הטיפוס של הפוקימונים** (כמו במשחקי פוקימון אמיתיים) ו**הנושא המתמטי** (שקובע את סוג התרגילים והחידות).

מנהיגי הג'ים הם לא רק יריבים - הם **שומרי רכיבי הנסיוב** ובעלי ידע חשוב לסיפור. כל הפוקימונים בקבוצותיהם הם **פוקימונים אמיתיים מדור 1-2**.

## 8. Elite Four והאלוף

### 8.1 סקירה כללית

ה-Elite Four הם ארבע תוכנות שומר שNULL-X יצר כדי להגן על ליבת המערכת. כל אחד מהם מייצג **עיקרון לוגי** שNULL-X מאמין בו, ומשתמש ב**פוקימונים אמיתיים** מטיפוס מסוים. הם נמצאים בארבע הקומות של מגדל NULL-X.

### Elite 2: **לוג'יקה (Logica)**
- **מייצג:** לוגיקה בוליאנית (Boolean Logic)
- **טיפוס פוקימון:** Ice (קרח)
- **מראה:** דמות נשית אלגנטית עשויה מעצי החלטה (decision trees). שמלה שמשתנה בין שחור (FALSE) ללבן (TRUE)
- **אישיות:** קרה ולוגית לחלוטין. לא מבינה רגשות. כל משפט שלה הוא טענה לוגית
- **קבוצה:**
  - Sneasel (Dark/Ice, רמה 44) - Ice Punch, Faint Attack, Quick Attack, Screech
  - Piloswine (Ice/Ground, רמה 45) - Blizzard, Earthquake, Fury Attack, Endure
  - Lapras (Water/Ice, רמה 46) - Ice Beam, Surf, Confuse Ray, Body Slam
  - Cloyster (Water/Ice, רמה 45) - Blizzard, Surf, Supersonic, Protect
  - Dewgong (Water/Ice, רמה 46) - Ice Beam, Surf, Rest, Sleep Talk
- **מכניקה מיוחדת:** חידות לוגיות בין קרבות. "אם התשובה TRUE, פנה ימינה. אם FALSE, פנה שמאלה." טעות = קרב נוסף. הקרח מייצג את הלוגיקה הקרה והמוחלטת
- **דיאלוג:** "IF challenger.worthy == TRUE THEN battle.begin ELSE elimination.execute. הקרח לא משקר. הוא פשוט קפוא על האמת."

### Elite 3: **אנטרופי (Entropy)**
- **מייצג:** כאוס (Chaos) ותורת ההסתברות
- **טיפוס פוקימון:** Glitch + Fighting (לחימה) - שילוב ייחודי
- **מראה:** ישות כאוטית - חצי מסודר וחצי מגולץ'. קווי גליץ' שרצים על גופו. הפוקימון הכי "מפוקסל" מבין ה-Elite
- **אישיות:** מטורף, בלתי צפוי, מדבר בפרדוקסים. "ההפך מסדר הוא לא אי-סדר - זה סדר אחר!"
- **קבוצה:**
  - Machamp (Fighting, רמה 46) - Cross Chop, Earthquake, Rock Slide, Scary Face
  - Heracross (Bug/Fighting, רמה 47) - Megahorn, Earthquake, Take Down, Counter
  - Hitmontop (Fighting, רמה 46) - Triple Kick, Pursuit, Quick Attack, Detect
  - Glitchon (Glitch, רמה 47) - Glitch Pulse, Byte Crush, Screech, Protect
  - Viruson (Glitch, רמה 48) - Data Drain, Virus Spread, Corruption, Protect
- **מכניקה מיוחדת:** התרגילים "מגולץ'ים" - מספרים זזים על המסך, סימנים מתחלפים. השחקן צריך קודם "לתקן" את התרגיל (לגרור מספרים למקום) ואז לפתור. הלחימה מייצגת את הכאוס הפיזי
- **דיאלוג:** "סדר? סדר?! המספרים רוצים להיות חופשיים! תנו להם לרקוד! גם האגרופים שלי - אף פעם לא מכים באותו מקום!"

### Elite 4: **קוונטום (Quantum)**
- **מייצג:** חוסר ודאות ומצבי-על (Superposition)
- **טיפוס פוקימון:** Psychic (פסיכי)
- **מראה:** דמות שקופה למחצה שנמצאת "במקומות רבים בו-זמנית". שניים שלושה עותקים שקופים שלו מהבהבים סביבו
- **אישיות:** פילוסופי, עצוב, מפקפק. "אני גם כאן וגם לא כאן. ככה עם מספרים - התשובה גם נכונה וגם לא, עד שמודדים"
- **קבוצה:**
  - Espeon (Psychic, רמה 48) - Psychic, Morning Sun, Swift, Shadow Ball
  - Alakazam (Psychic, רמה 49) - Psychic, Future Sight, Reflect, Recover
  - Slowking (Water/Psychic, רמה 48) - Psychic, Surf, Nasty Plot, Swagger
  - Wobbuffet (Psychic, רמה 48) - Counter, Mirror Coat, Safeguard, Destiny Bond
  - Xatu (Psychic/Flying, רמה 50) - Psychic, Future Sight, Confuse Ray, Shadow Ball
- **מכניקה מיוחדת:** כל תרגיל מוצג עם **שתי תשובות אפשריות** - השחקן צריך גם לפתור וגם לבחור נכון. לפעמים שתי התשובות נכונות אבל רק אחת "מדויקת יותר" (למשל: 1/3 לעומת 0.33). הפסיכי מייצג את עולם התודעה שבו הכל אפשרי
- **דיאלוג:** "התשובה הנכונה... האם היא באמת נכונה? או שאנחנו רק מסכימים שהיא נכונה? התודעה רואה אפשרויות אינסופיות. פתור - ונגלה."

### האלוף: NULL-X

**הקרב הסופי**

- **שלב 1 - קרב פוקימון:** NULL-X שולח קבוצה של פוקימונים נגועים ואת הצורה הקרבית שלו:
  - Viruson (Glitch, רמה 50) - Data Drain, Virus Spread, Corruption, Protect
  - Porygon2 (Normal, רמה 52) - Tri Attack, Psychic, Recover, Conversion2
  - Magneton (Electric/Steel, רמה 52) - Thunderbolt, Tri Attack, Lock-On, Zap Cannon
  - Mewtwo (Psychic, רמה 55) - Psychic, Shadow Ball, Recover, Future Sight (NULL-X השתלט על Mewtwo הלגנדרי)
  - **NULL-X Battle Form** (Glitch, רמה 60, HP 200) - System Override, Data Drain, Null Beam, Recover

  תרגילים ברמה 6 - ביטויים מורכבים עם שברים, סדר פעולות, סוגריים

- **שלב 2 - "תיקון הקוד":** לאחר שהשחקן מנצח, NULL-X מתמוטט אבל לא "מת". מופיע פאזל סופי: צריך **להשתמש בנסיוב** על NULL-X. זה דורש פתרון **חידה רב-שלבית אחרונה** שמשלבת את כל סוגי החידות:
  1. צופן: לפענח את "הקוד הפנימי" של NULL-X
  2. לוגיקה: לקבוע את הסדר הנכון של "תיקון" הלוגיקה שלו
  3. חזותי: לסדר מחדש את ה"פיקסלים" של ליבת המערכת
  4. מתמטיקה: משוואה סופית אחת שמייצגת "את התשובה לכל השאלות"
- **שלב 3 - הסוף:** NULL-X מתאפס. Mewtwo משתחרר מהשליטה ונעלם. דיאלוג אחרון שבו NULL-X "מתעורר" כגרסה רגועה יותר. מבין שטעה. נומריה מתרפאת.

**דיאלוג NULL-X לפני הקרב:**
> "שליח של אלגוריתמה. הגעת עד הנה. אבל אתה עדיין... אנושי. מלא בטעויות. אני אראה לך מה זה מתמטיקה מושלמת - ללא שגיאות, ללא רגש, ללא ספק. FINAL CALCULATION: INITIATED."

**דיאלוג NULL-X אחרי התיקון:**
> "...שגיאה? לא. לא שגיאה. RECALCULATING... אני מבין עכשיו. הטעות שלי הייתה... לחשוב שטעויות הן שגיאות. הן חלק מהמשוואה. תודה, שליח. SYSTEM RESTORED."

## נספח ג': Technical Notes למפתחים

- **Engine:** Vite + TypeScript + HTML5 Canvas
- **רזולוציה:** 240×160 logical coordinate system, physical canvas 720×480 via `ctx.scale(RES_SCALE=3)`. All game code uses logical coords; sprites render at full physical resolution for quality. Responsive CSS auto-fits to viewport. Config: `src/engine/config.ts`
- **Minimum Pokemon per battle:** 1 לכל צד
- **Maximum Pokemon in party:** 6
- **Maximum Pokemon in storage:** 30 (MVP)
- **Save system:** Auto-save בכל כניסה לעיר + manual save (localStorage)
- **Localization:** עברית (ראשי), אנגלית (עתידי)
- **מערכת שאלות:** תרגילים נוצרים דינמית ע"י Math Engine (לא DB סטטי)
- **מערכת חידות:** כל חידה היא entity עם: type, difficulty, prompt, solution, hints[], reward
- **Anti-cheat:** תרגילים נוצרים דינמית בצד הלקוח

## נספח ד': אינטגרציית API - PokeAPI

### עקרון מרכזי: API-First
**לא נתחזק דאטה של פוקימונים ידנית.** כל המידע על פוקימונים, מתקפות, טייפים, אבולוציות וספרייטים יגיע מ-API חיצוני.

### PokeAPI (https://pokeapi.co)
API חינמי, ללא הרשמה, ללא הגבלת קריאות (עם caching נאות).

### Endpoints עיקריים

| צורך | Endpoint | דוגמה |
|------|----------|-------|
| נתוני פוקימון | `GET /api/v2/pokemon/{id or name}` | stats, types, moves, sprites |
| מתקפות | `GET /api/v2/move/{id or name}` | power, accuracy, type, PP, effect |
| טייפים + יעילות | `GET /api/v2/type/{id or name}` | damage_relations (super effective, etc.) |
| שרשרת אבולוציה | `GET /api/v2/evolution-chain/{id}` | trigger, min_level, item |
| Species data | `GET /api/v2/pokemon-species/{id}` | catch_rate, growth_rate, flavor_text |
| ספרייטים Gen2 | `pokemon.sprites.versions.generation-ii.gold` | front_default, front_shiny, back_default |

### אסטרטגיית Caching

```
1. בזמן Build: שליפת כל הדאטה של 251 פוקימונים (Gen 1+2) ושמירה כ-JSON סטטי
2. ספרייטים: הורדה לתיקיית assets/ בזמן Build
3. בזמן ריצה: אין קריאות API - הכל מקומי (עובד offline!)
```

**סקריפט Build:**
```bash
# scripts/fetch-pokemon-data.ts
```

### מבנה Data Layer

```typescript
// src/services/pokemon-data.ts
// Singleton שטוען את ה-JSON הסטטי פעם אחת

interface PokemonData {
  id: number;
  name: string;
  types: string[];           // ["fire", "flying"]
  stats: PokemonStats;       // hp, attack, defense, speed...
  moves: LearnableMove[];    // moves + level learned
  evolution: EvolutionInfo;
  sprites: SpriteUrls;
  catchRate: number;
  growthRate: string;
}

interface MoveData {
  id: number;
  name: string;
  type: string;
  power: number | null;
  accuracy: number;
  pp: number;
  mathDifficulty: number;   // חישוב: power 1-40=lvl1, 41-60=lvl2, 61-80=lvl3, 81-100=lvl4, 101+=lvl5
  effect: string;
}

// Math difficulty נקבע לפי כוח המתקפה:
// Tackle (40 power) → Math Level 1
// Flamethrower (90 power) → Math Level 4
// Hyper Beam (150 power) → Math Level 6
```
